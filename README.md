## What I Learned

- Creating forms with the `<form>` element
- Grouping inputs using `<fieldset>` and `<legend>`
- Using different input types such as text, email, number, radio buttons, and checkboxes
- Adding validation with attributes like `required`, `min`, `max`, and `placeholder`
- Creating dropdown menus with `<select>` and `<option>`
- Using `<textarea>` for comments
- Improving accessibility by linking `<label>` elements with form controls
